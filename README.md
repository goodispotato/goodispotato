### Sossbar

소통 방식이나 책임감 같은 소프트스킬을 보여주기 위한 팀 협업 프로필 서비스입니다.<br/>
포트폴리오는 깃허브처럼 보여줄 수 있는 수단이 다양하지만,<br/>
소프트스킬을 공유할 수 있는 서비스는 부재합니다.<br/>
Sossbar는 PM, 디자이너, 개발자 모두가 함께한 팀원의 소프트스킬을 확인하고 후기를 남길 수 있는 공간입니다.

<br/>

**주요 기능**

소프트스킬 후기 공유 및 열람<br/>
프로젝트 상태별 필터링 및 커서 기반 페이지네이션<br/>
UUID 기반 초대 링크로 팀 참여<br/>
팀 확정/참여 알림

<br/>

**담당 역할**

후기 작성 구현<br/> 
후기 전체 조회 및 프로젝트별 조회 구현<br/>
페이지네이션 구현<br/>
팀원 추가/삭제 및 팀장의 팀 확정 구현<br/> 알림 기능 구현<br/>
